# Personalized Travel Itinerary Planner ✈️

A modern travel planning web application that helps users organize personalized trips based on their destination, budget, travel dates, interests, and travel style.

## Features

- Modern landing page and travel dashboard
- Trip creation with customizable preferences
- Day-by-day itinerary presentation
- Travel activity and destination recommendations
- Budget estimation
- Create, view, edit, and delete trips
- Save trip information in browser local storage
- Responsive design for desktop and mobile
- Dark and light mode

## Technologies Used

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS
- **Storage:** Browser Local Storage

## Getting Started

### Prerequisites
- Node.js
- npm
- Visual Studio Code (recommended)

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd personalized-travel-planner
```

Install dependencies:

```bash
cd frontend
npm install
```

Start the application:

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### Build for Production

```bash
npm run build
```
